# QuickInstall Hub

QuickInstall Hub is a platform that allows users to select multiple applications from a web interface and generates a single, cryptographically signed installer that downloads and silently installs all selected apps on their Windows machine.

## Architecture

1. **Frontend (`/web`)**: Next.js (React) storefront where users pick software.
2. **Backend (`/api`)**: FastAPI backend that manages the software catalog and generates cryptographically signed manifests.
3. **Desktop Agent (`/agent`)**: A standalone Windows executable (`QuickInstall.exe`) that reads the manifest, verifies the Ed25519 signature, downloads the software, checks SHA-256 hashes, and runs silent installers.

---

### Running the Platform
I have configured the project so you only need to run **one command**! The frontend will automatically boot up the backend API in the background at the same time.

1. Open a terminal and navigate to the project's `web` folder:
   ```cmd
   cd quickinstall-hub\web
   ```
2. Start everything:
   ```cmd
   npm run dev
   ```

*The Next.js storefront will open on **http://localhost:3000** and the FastAPI backend will run on **http://localhost:8000** automatically!*

---

## Generating and Running an Installer

1. Visit **http://localhost:3000** in your browser.
2. Select a few applications (e.g., Firefox, VLC) by clicking the checkboxes.
3. A **Selection Tray** will appear at the bottom. Click **"Generate QuickInstall"**.
4. The backend will return a unique manifest URL (e.g., `/api/v1/manifests/abc-123`).
5. Run the compiled agent to install your apps!

### Running the Desktop Agent

If you have built the `.exe` via `agent/build.ps1`, you can run it via command prompt:

```cmd
cd agent\dist
QuickInstall.exe <manifest_id>
```
*(Replace `<manifest_id>` with the ID generated by the frontend, e.g., `511674a2-95f0-466d-a1db-bc4a9f9d784a`)*

To run the agent directly using Python instead of the compiled `.exe`:
```cmd
cd agent
pip install -r requirements.txt
python main.py <manifest_id>
```

## Admin Dashboard

To update download links, application versions, or SHA-256 hashes, visit:
**http://localhost:3000/admin**

## Deployment (Production)

* **Backend**: Use the included `api/Dockerfile` to deploy to Google Cloud Run or Render. Exposes port `8080`.
* **Frontend**: Deploy to Vercel. Be sure to set the `NEXT_PUBLIC_API_URL` environment variable to your deployed backend URL.
* **Agent**: Run `agent/build.ps1` on a Windows machine to bundle the public key into a standalone `QuickInstall.exe` executable.
